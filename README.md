# G3O Spatial Solutions

Responsive, one-page geospatial consultancy website for G3O Spatial Solutions.

## Website
The site is a lightweight static HTML/CSS page with no build dependencies. The source is `index.html`.

## Local preview
Open `index.html` in a browser, or run a local static server from the repository root.

## Deployment
GitHub Actions deploys the repository root to GitHub Pages using `.github/workflows/deploy.yml`.

Expected URL:
https://g3ospatialsolutions.github.io/g3o-spatial-solutions/

If Pages has not been enabled yet, open **Settings → Pages** and set the build/deployment source to **GitHub Actions**.

## Content principles
- Do not publish unapproved projects, client materials, testimonials, or credentials.

- No academic ghostwriting, fabricated research, impersonation, or completion of student assessments.
- Client confidentiality is the default; obtain written permission before publishing project outputs.
- G3O is presented as an independent consultancy and does not claim institutional endorsement.
- No secrets, tokens, client datasets, or unpublished research belong in this repository.
