# G3O Spatial Solutions website

Astro-based static website for G3O Spatial Solutions, intended for GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The intended site URL is:
https://g3ospatialsolutions.github.io/g3o-spatial-solutions/

## Deployment

The GitHub Actions workflow in .github/workflows/deploy.yml builds the Astro site and deploys dist/ to GitHub Pages.

## Content governance

- Do not publish unapproved projects, client materials, testimonials, or credentials.
- Portfolio and testimonials are intentionally omitted until verified content and publication permissions are supplied.
- Web GIS is labeled as an emerging capability.
- Review legal policy drafts and actual privacy practices before launch.
- No secrets, tokens, client datasets, or unpublished research belong in this repository.
